## Context

Azure is a strategic cloud platform for workloads that benefit from managed services, identity integration, and operational consistency. Because platform choice affects cost, deployment shape, and long-term maintainability, the radar needs an explicit decision record.

## Decision

Keep Azure as an accepted platform choice for workloads where its managed services and operational model align with team capabilities and delivery needs.

## Consequences

- Teams can select Azure confidently for suitable platform work.
- Architecture decisions should still document service-level trade-offs, not simply default to Azure everywhere.
- Cost, observability, and identity practices must be included in implementation planning.
