## Context

Cypress is used as a high-confidence browser testing tool for product flows where fast feedback and clear debugging matter. The team needs an explicit decision record because test tooling shapes developer workflow, CI runtime, and confidence in release readiness.

## Decision

Keep Cypress as an accepted testing tool for end-to-end and component-level browser scenarios where its developer experience and diagnostics are valuable.

## Consequences

- Teams have a clear default for browser automation scenarios.
- Test suites should remain focused to avoid slow feedback loops.
- Projects should pair Cypress coverage with lower-level tests where browser automation would be excessive.
